# Как внести вклад / Contributing

Добро пожаловать в проект RP-Chat-Overlay! Мы рады любым вкладам: исправлениям багов, новым функциям, улучшению документации и переводам.

## 1. Начало работы

1. Сделайте **fork** репозитория.
2. Склонируйте свой fork:
   ```bash
   git clone https://github.com/ВАШ_ИМЯ/RP-Chat-Overlay.git
   cd RP-Chat-Overlay
   ```
3. Добавьте upstream remote:
   ```bash
   git remote add upstream https://github.com/Ven4esters/RP-Chat-Overlay.git
   ```
4. Установите зависимости для разработки:
   ```bash
   pip install -r source/requirements.txt
   pip install ruff mypy pytest pytest-cov bandit safety pip-audit
   ```

## 2. Политика веток

- **Ветки создаются по тикету**: `feature/описание`, `fix/описание`, `docs/описание`.
- **Не работайте напрямую в `main` или защищённых ветках.**
- Перед beginning работы синхронизируйтесь с upstream:
  ```bash
  git fetch upstream
  git checkout main
  git merge upstream/main
  ```

## 3. Стиль кода

Следуйте [`STYLEGUIDE.md`](STYLEGUIDE.md). Перед отправкой PR обязательно запустите:

```bash
# Линтер
ruff check source

# Форматтер
ruff format source

# Проверка типов
mypy source/app --ignore-missing-imports

# Тесты
python -m pytest source/tests -v
```

## 4. Коммиты

Используйте **Conventional Commits**:

| Тип | Когда использовать |
|---|---|
| `feat` | Новая функция |
| `fix` | Исправление бага |
| `docs` | Изменение документации |
| `style` | Форматирование, отсутствующие точки с запятой и т.д. |
| `refactor` | Рефакторинг кода |
| `test` | Добавление или исправление тестов |
| `chore` | Изменение процесса сборки, инструментов |

Примеры:
```
feat: добавить системные модули с возможностью отключения
fix: dlx.translate() больше не отправляет source_lang="auto" в DeepL
docs: обновить README с разделом про DeepLX в России
```

## 5. Pull Request

1. Создайте ветку от `main`:
   ```bash
   git checkout -b feature/моя-изменение
   ```
2. Внесите изменения и закоммитьте их.
3. Запустите все проверки (линтер, форматтер, тесты).
4. Откройте Pull Request на GitHub.
5. Заполните шаблон PR (см. `.github/pull_request_template.md`).
6. Дождитесь прохождения CI и одобрения ревьюером.
7. После слияния удалите свою ветку.

### Требования к PR

- **Маленькие PR**: ориентир до 300–400 строк изменений; большие — дробить.
- **Тесты**: новые функции и исправления багов должны иметь тесты.
- **Документация**: обновляйте README/CHANGELOG, если нужно.
- **CI зелёный**: все quality gates пройдены.
- **Ревью**: минимум одно одобрение; для критичных модулей — два.
- **Не мержите с «красным» CI, конфликтами, незакрытыми блокирующими комментариями.**
- **Запрещён self-merge** без политики исключений.
- **Никаких force-push в общие ветки**; история должна быть понятной.

## 6. Отправка багов и предложений

- Используйте [GitHub Issues](https://github.com/Ven4esters/RP-Chat-Overlay/issues).
- Для багов укажите: шаги воспроизведения, ожидаемое и фактическое поведение, версию программы, скриншоты (если есть).
- Для предложений описывайте проблему, которую хотите решить, и почему текущее решение не подходит.

## 7. Переводы

Интерфейс программы двуязычный (RU + EN). Все строки интерфейса находятся в `source/app/i18n.py`. При добавлении новой строки обязательно добавьте перевод на оба языка.

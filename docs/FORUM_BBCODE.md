# Материалы для новой темы форума

Новый текст темы и графика теперь поддерживаются отдельно от кода приложения в [`forum-topic/`](forum-topic/):

- [`TOPIC_RU.bbcode`](forum-topic/TOPIC_RU.bbcode) — готовый BBCode-шаблон на русском;
- [`README_FORUM_RU.md`](forum-topic/README_FORUM_RU.md) — размеры, хостинг, шаблонные поля и проверка перед публикацией;
- [`assets/`](forum-topic/assets/) — оригинальный баннер 1200×500 и девять плашек 1200×62;
- [`build_assets.py`](forum-topic/build_assets.py) — исходник графики.

Прежние растровые файлы, связанные с прежним вариантом темы, удалены. Новые материалы созданы в соответствии с руководством «Тема под ключ»: прямые URL изображений, баннер в начале публикации, заголовки-разделители в виде плашек, списки вместо таблиц и только поддерживаемый BBCode.

Перед публикацией загрузите PNG на хостинг с прямыми URL, замените все адреса `YOUR-DIRECT-IMAGE-HOST` и поля в двойных фигурных скобках в BBCode. Не публикуйте блок загрузки, пока релизная сборка, контрольные суммы и соответствующий ей отчёт VirusTotal не готовы.

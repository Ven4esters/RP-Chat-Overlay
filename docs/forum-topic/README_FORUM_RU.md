# Набор для новой темы форума

## Состав

- `TOPIC_RU.bbcode` — новый русский текст темы, готовый к вставке после замены всех шаблонных ссылок и релизных значений.
- `assets/banner-fivem-chat-overlay.png` — баннер **1200×500 px**.
- `assets/section-01.png` … `assets/section-09.png` — девять плашек **1200×62 px**.
- `build_assets.py` — исходник этих оригинальных PNG; запускается с Pillow и не меняет файлы кода приложения.

Для пересборки установите Pillow в отдельную среду и запустите скрипт из корня репозитория:

```powershell
py -3 -m pip install Pillow
py docs/forum-topic/build_assets.py
```

Старые растровые изображения из `source/images/forum/` удалены; этот набор создан заново по требованиям приложенного руководства: сначала баннер, затем текстовый заголовок; заголовки разделов — плашки; текстовые блоки — простые списки вместо таблиц. Плашки нужно вставлять без `[center]`, чтобы они занимали доступную ширину.

## Подготовка прямых URL для `[img]`

1. Загрузите PNG из `assets/` на хостинг, выдающий прямой URL файла (ссылка должна открывать именно `.png`, а не страницу-галерею).
2. В `TOPIC_RU.bbcode` замените `https://YOUR-DIRECT-IMAGE-HOST.example/` на базовый URL загруженной папки.
3. Подставьте реальные значения вместо `{{VERSION}}`, `{{RELEASE_URL}}`, `{{MD5}}`, `{{SHA256}}` и `{{VIRUSTOTAL_URL}}`.
4. Проверьте получившиеся картинки, ссылки, BBCode и сохранённый пост на телефоне и компьютере.

Не вставляйте плашки в `[center]`; не используйте таблицы, HTML, Markdown или атрибуты вроде `width=` в `[img]`. В документе соблюдены ограничения из инструкции: только обычные поддерживаемые BB-теги, прямые ссылки на изображения и списки для структуры.

## Контроль перед отправкой

- Баннер отображается первым элементом и имеет размер 1200×500.
- Все плашки 1200×62, прямые ссылки открывают PNG, а не страницу хостинга.
- В BBCode не осталось `YOUR-DIRECT-IMAGE-HOST` или фигурных шаблонов.
- EXE, обе контрольные суммы и VirusTotal-отчёт относятся к одному и тому же конечному EXE.
- Ни одно утверждение о «чистой» проверке не делается без завершённого отчёта VirusTotal.

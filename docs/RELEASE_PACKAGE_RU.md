# Windows-сборка и релизная информация

## Создание EXE и сопутствующих файлов

В Windows 10/11 с Python 3.12 запустите `source/build_exe.bat`. Скрипт найдёт Python, создаст окружение, установит зависимости и соберёт `dist/FiveMChatOverlay.exe`. После успешной сборки он вызовет `source/tools/write_release_info.py` и положит рядом с EXE:

- `FiveMChatOverlay-README.txt` — версию, UTC-время сборки, размер, MD5/SHA-256, описание приложения, требования и ссылки;
- `FiveMChatOverlay.exe.md5`;
- `FiveMChatOverlay.exe.sha256`.

Готовый Windows-артефакт можно также собрать через GitHub Actions: **Build Windows exe → Run workflow**. При ручном запуске задание добавляет EXE и три файла описания/контрольных сумм в `dist/` выбранной ветки и публикует их как downloadable artifact. При сборке по тегу файлы прикладываются к GitHub Release.

## VirusTotal

Сборочный скрипт не отправляет файлы в VirusTotal и не может утверждать, что EXE проверен. В текстовом README статус явно указан как **NOT SCANNED**, а URL по SHA-256 — это только страница поиска/загрузки, не подтверждение анализа.

Для настоящей проверки загрузите именно финальный EXE в VirusTotal, дождитесь отчёта и убедитесь, что SHA-256 в нём совпадает с `FiveMChatOverlay.exe.sha256`. При пересборке повторите расчёт сумм и проверку. Не публикуйте формулировку «проверено VirusTotal» без отчёта, относящегося к этой сумме.

## Публикация темы форума

Используйте новый текст и графику из [`forum-topic/`](forum-topic/). После загрузки прямых PNG-ссылок на надёжный хостинг замените placeholder-URL и релизные значения в `TOPIC_RU.bbcode`. Перед публикацией сверяйте информацию о загрузке и VirusTotal с файлами рядом с тем же EXE.

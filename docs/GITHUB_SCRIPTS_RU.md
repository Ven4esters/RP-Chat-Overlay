# BAT-скрипты для GitHub

Скрипты находятся в `tools/` и рассчитаны на Windows. Они работают с GitHub через GitHub CLI (`gh`), а не через браузер.

## Требования перед запуском

1. Установите **Git for Windows** и **GitHub CLI**: <https://cli.github.com/>.
2. Один раз выполните в терминале `gh auth login` и войдите в аккаунт, у которого есть права записи в нужный репозиторий.
3. Проверьте, что в папке-источнике нет секретов, паролей и файлов, которые нельзя публиковать. Скрипт загрузки пропускает файлы `.env` и распространённые папки окружений, но это не заменяет проверку содержимого.

## Загрузить папку в существующий репозиторий

Запустите `tools\upload_to_existing_github_repo.bat`.

Скрипт запросит папку с файлами (Enter выбирает `dist` этого проекта) и существующий репозиторий в формате `ВЛАДЕЛЕЦ/ИМЯ`. После подтверждения он скопирует файлы в корень клона, создаст коммит и отправит его в ветку, клонированную из ветки репозитория по умолчанию. Файлы с совпадающими путями могут быть заменены. Если Git не настроен, скрипт запросит имя автора и email только для локального клона. Для доступа к репозиторию нужны права записи; защищённая ветка может требовать pull request.

## Создать GitHub Release в существующем репозитории

Запустите `tools\create_github_release.bat`.

Скрипт запросит:

- целевой репозиторий в формате `ВЛАДЕЛЕЦ/ИМЯ`;
- тег и название релиза;
- папку с файлами (Enter выбирает `dist` этого проекта);
- автоматически сгенерированные или введённые вручную заметки;
- нужно ли пометить релиз как предварительный.

После подтверждения он опубликует релиз и прикрепит файлы из выбранной папки. Если указанный тег ещё не существует, GitHub CLI может создать его на основе основной ветки репозитория. Существующий тег/релиз нельзя повторно использовать без предварительной проверки.

Оба скрипта показывают URL результата. Ошибки авторизации, прав доступа или существующий тег нужно устранить отдельно и запустить скрипт повторно. Скрипты не выполняют сканирование VirusTotal и не подтверждают безопасность загружаемых файлов.

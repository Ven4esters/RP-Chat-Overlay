# Вспомогательный BAT для GitHub

В `tools/` оставлен один GitHub-скрипт: `github_publish.bat`. Он рассчитан на Windows и использует GitHub CLI (`gh`), а не браузер.

## Требования

1. Установите **Git for Windows** и **GitHub CLI**: <https://cli.github.com/>.
2. Выполните `gh auth login` и войдите в аккаунт с правами на нужный репозиторий.
3. Проверьте выбранную папку на секреты, пароли и файлы, которые нельзя публиковать. При копировании скрипт пропускает `.env` и распространённые папки окружений, но это не заменяет ручную проверку.

## Использование

Запустите `tools\github_publish.bat` и выберите действие:

- **U — загрузить папку в существующий репозиторий.** Скрипт спросит папку и репозиторий в формате `ВЛАДЕЛЕЦ/ИМЯ`, затем скопирует содержимое папки в корень клона, создаст коммит и отправит его в клонированную ветку по умолчанию. Enter выбирает `dist` этого проекта. Файлы с совпадающими путями могут быть заменены; защищённая ветка может требовать pull request.
- **R — создать GitHub Release в существующем репозитории.** Скрипт спросит репозиторий, тег, название, папку с файлами, заметки и тип релиза. Enter в запросе папки выбирает `dist`. Если тега ещё нет, GitHub CLI может создать его на основе основной ветки.
- **Q — выход.**

Для загрузки целой папки проекта в другой репозиторий выберите её корень как исходную папку: скрипт переносит содержимое выбранной папки, сохраняя вложенные пути. Перед подтверждением проверьте целевой репозиторий и возможные совпадения файлов.

Скрипт не сканирует файлы через VirusTotal и не подтверждает их безопасность. Повторное использование существующего тега Release может завершиться ошибкой.
